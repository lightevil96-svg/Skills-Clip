# Skills-Clip

Kumpulan skill untuk analisis dan penyuntingan video pendek.

## Skill tersedia

### VTuber Conversation Clip
Lokasi: [`vtuber-conversation-clip/SKILL.md`](vtuber-conversation-clip/SKILL.md)

Skill ini merumuskan gaya dari referensi video VTuber berdurasi 23,6 detik: potongan percakapan cepat, subtitle berkode warna per pembicara, pergantian close-up, reaction shot, serta meme/stiker yang memperkuat punchline.

## Struktur

- `vtuber-conversation-clip/SKILL.md` — instruksi utama skill.
- `vtuber-conversation-clip/references/style-reference.md` — observasi visual dan peta ritme dari video referensi.
- `vtuber-conversation-clip/references/render-workflow.md` — alur analisis, render FFmpeg, dan quality control.

## Catatan sumber

Video referensi dipakai sebagai bahan analisis, bukan disimpan di repository. Angka teknis dan timestamp di dokumen referensi adalah hasil pengamatan pada klip tersebut; gunakan sebagai titik awal, bukan preset kaku untuk semua video.
